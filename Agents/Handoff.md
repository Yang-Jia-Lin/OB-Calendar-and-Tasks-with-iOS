# 当前交接

更新：2026-11-07。当前要求以[产品需求](../Notes/1-产品需求.md)和[架构设计](../Notes/2-架构设计.md)为准。

## 最新决定

- Windows 桌面版承担待办、日程、计时与云同步；OB 只保留 Components 按钮及本机状态连接。
- Mac 主要用原生日历和提醒事项，开发轻量本机计时工具。用户已明确确认：结束后写入 iCloud 日历。
- 活动计时不上传、不跨 Windows／Mac 接管；同一电脑内 OB 与 App 共用一个会话。Mac 不依赖 Windows 在线，结束只记工时、不自动完成提醒事项。
- Windows 首版同时包含主窗口、桌面底层月历＋当日摘要、灵动岛和拖动安排／撤销；先功能后视觉。Windows 睡眠／休眠继续计时，明确退出保存为暂停；日记手动和自动更新继续保留。
