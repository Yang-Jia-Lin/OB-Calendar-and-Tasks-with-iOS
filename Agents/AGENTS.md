# 项目开发约定

更新：2026-11-08。路径均相对项目根目录。

- 接续先读 `Agents/Handoff.md`，再读 `Notes/0-开发约定.md`、`Notes/1-产品需求.md`、`Notes/2-架构设计.md`；重新核对实际工作区与 Git 状态。当前需求覆盖旧交接和归档中的开发方向。
- 当前目标：Windows 完整桌面 App 负责本机计时与云同步；OB 保留轻量按钮和本机状态连接；Mac 主要使用原生 App，另做轻量计时，结束后写入 iCloud 日历。活动计时不跨 Windows／Mac 同步，不把全局锁或接管列为前置需求。
- 当前 Windows 0.1.2、OB 0.8.1；OB 仅连接桌面后台，保留课题按钮、日记及启动时自动关闭反向链接／全部属性，默认隐藏左侧 Templater、Git、AI 对话（新标签页）和 Insert Callout。不得重新带回独立计时、云认证和同步引擎。用户已完成桌面交接与备注往返；只读核对保留 3 个课题绑定。Mac 待开发，实际平台验收仍按 Handoff 区分。
- 文档收敛为 README、Notes 的开发约定／需求／架构／使用与迁移／近期日志，以及本入口和当前交接。旧全文位于 `Notes/Archive/2026-11-07-OB完整工作台/`，只在具体历史问题需要时读取。每次实质变更更新近期日志，交接只保留当前需要的信息。
- 保留稳定任务／工时身份、原有课题绑定、凭据保护、会话和待同步／恢复状态。新旧宿主不能同时充当计时与队列写入者；实际交接须先按需求和迁移清单验收。
- 源码与测试在 Coding；检查产物在 Agents/Tests，截图在 Agents/Tests/Visuals；旧程序备份在 Agents/Backups。Results/Obsidian 仅插件三文件，Results/PC 仅安装包／说明／校验，Results/Preview 为交互预览，Results/Probes 为既有探针。旧 0.7.0 桥接版保留，其他旧版归入各端 Archive；秘密、会话和本机依赖不入 Git。
- 当前插件新版本通过相关检查后，按既有授权执行 `npm run release`，仅覆盖 `D:\笔记\.obsidian\plugins\calendar-task-timer` 的三程序文件；变化前备份，保留全部用户数据，不自动重载。构建／渠道／保留回退规则见开发约定；新桌面 App 的发布方式另行建立。
- 既有授权：每次真正的新版本检查通过后，提交本次相关代码、文档和产物并正常 push 至已核对的 origin/main，无需逐次询问；简洁版本标题，不强推、不覆盖无关改动。纯文档工作不虚增版本、不自动发布／推送；用户明确要求提交时执行。
- 归档移动前核对解析后的源／目标都在本项目，保持历史正文和证据，仅允许修正相对链接及增加归档提示。不要重建用户已删除旧存档，不清理业务数据；遇到审批或远端问题按实报告，不绕过。
