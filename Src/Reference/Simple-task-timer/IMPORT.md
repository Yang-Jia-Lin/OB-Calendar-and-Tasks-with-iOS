# 参考源码说明

此目录保存用户已经试用并认可的「简洁待办计时」0.1.0 开发源码。

- 来自同一任务中开发的独立计时插件，保留其 MIT 许可证。
- 仅复制源码、构建脚本、离线测试、浏览器示例和文档，共 18 个原始文件；复制时逐一校验 SHA-256。
- 没有复制安装后的 `data.json`、`sessions/`、Apple 凭据或真实用户数据。
- 当前只作为改版参考，不是本仓库默认构建入口。
- 根目录使用上游 FCR 的 TypeScript / esbuild 构建；此参考实现使用独立的 CommonJS 无依赖构建与 Node 测试。
- 应把领域逻辑整合到主源码，而不是让用户长期安装两个插件。
- 目录整理后位于 `Src/Reference/Simple-task-timer/`；构建输出统一到项目根目录的 `Results/Reference/Simple-task-timer/`，预览和检查脚本已同步调整。
