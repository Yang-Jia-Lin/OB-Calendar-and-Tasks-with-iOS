# 简洁待办计时

面向 Windows Obsidian 的小插件。使用已有的 Full Calendar Remastered（FCR）连接，完成「选择待办 → 正向计时 → 完成并写入实际日历时间」的流程。中文界面，不含 AI、番茄动画或复杂规划功能。

## 首版范围

- 在一个页面添加、查看、完成普通 Markdown 待办，日期可留空。
- 开始、暂停、继续、结束计时。暂停期间不计时；每段实际工作时间分别创建日历日程。
- 「结束并完成」：先把各时间段写入日历，全部成功后完成原待办。
- 「只记时间」：保存日历记录，待办仍保持未完成。
- 查看某天已加载的单次日程；新增、修改普通单次定时日程。
- 可以选择 FCR 已加载的单次、有日期待办，保留原任务身份并通过 FCR 完成。
- 云端写入失败时保留待同步记录，点击重试。通过确定的 CalDAV UID 避免重试产生多份云端记录。

**Apple 新版「提醒事项」尚未在这个插件中接入。** OB 待办不会自动变成 Apple 提醒事项。FCR 返回的旧版升级占位提示不会被当作真实任务。FCR 未排程远程待办的接口没有用于首版；FCR 来源目前仅显示其事件缓存中已加载的带日期单次任务。没有接入非官方 iCloud CloudKit 登录，也不收集 Apple 账户密码或验证码。

## 安装

1. 需要 Obsidian 1.12.7+，并启用 FCR 0.13.7（本次核对的接口版本）或兼容版本。FCR 中应先连接好可写的 iCloud 日历。
2. 将安装包的 `simple-task-timer` 文件夹复制到笔记库的 `.obsidian/plugins/` 下。
3. 重新加载 Obsidian，在「设置 → 第三方插件」启用「简洁待办计时」。不需要替换或修改 FCR。
4. 从左侧计时图标或命令面板打开「待办计时」。
5. 点击「连接日历」。FCR 会显示授权窗口，需要读取事件、写入事件、读取日历来源、刷新来源和打开日历权限。
6. 在「计时写入」中明确选择一本 iCloud 日历；不会擅自选择默认日历。
7. 添加一条测试待办，计时几秒，再点「结束并完成」。核对 iCloud 网页或 iPad 上的日程时间和标题。

FCR 的 API 令牌优先保存在 Obsidian SecretStorage 中；不复制 FCR 的 Apple 凭据。若宿主不提供 SecretStorage，授权仅保存在本次内存会话，下次需要重新连接。

## 数据位置与恢复

- 待办默认保存在 `待办计时/待办.md`，采用标准复选框、可选 `📅 YYYY-MM-DD` 日期和隐藏的稳定 ID。可随用户已有的笔记同步方案同步；插件自身不提供云端笔记同步。
- 可以直接在该笔记修改标题、日期和勾选状态。只有该指定文件中的复选框由插件维护，不扫描其他笔记。
- 每台设备的计时和待同步记录单独保存到 `.obsidian/plugins/simple-task-timer/sessions/<设备编号>.json`，有前一个有效版本 `.previous`。不要删除这个目录，除非已经确认云端写入完整并另有备份。
- 重新启动 OB 时，未结束的计时会恢复为暂停，计到最后一次持久化心跳（每 15 秒），不把关机期间算作工作。异常关机最多可能少计约 15 秒。
- 电脑睡眠但 OB 没有重启时，正向计时按真实钟表时间计算，因此离开工作前应主动暂停。
- 日历记录先持久化到本机，再进行云端写入。写入失败保留待同步；若日历已写入但原待办完成失败，可重试完成，或主动选「仅保留日程」。
- 插件不删除已有日历日程。取消或卸载插件不会自动删除待办文件与历史日历记录。

## 已知边界

- 接收计时记录的来源限定为可写的 CalDAV 日历（包括 iCloud），暂不直接写入 Google Calendar 来源，因为首版的重试幂等性依赖 CalDAV 稳定 UID。
- 暂不自动完成重复待办；不展示重复日程展开结果。可用「完整日历」打开 FCR。全天、跨日及重复日程的编辑交给 FCR。
- 日历日视图显示 FCR 已加载的数据，不是 iCloud 全历史导出，也不能当作完整日历备份。
- 在真实 Obsidian／iCloud 账户中完成端到端验证后，才能确认当前账户的 FCR 授权和云端写入可用。浏览器预览使用示例数据，离线测试不等于云端验证。

## 开发与验证

无构建依赖，不需要执行 `npm install`。

```text
npm run build
npm run check
npm test
node Scripts/preview-server.cjs
```

本项目根目录的 `Results/Reference/Simple-task-timer` 是安装目录。此参考目录内的 `Src/` 是独立编写的插件代码；`Tests/` 包含时间段、持久化、失败重试、幂等写入和 Markdown 身份测试。`Preview/` 是开发预览宿主，使用示例数据，不访问 Apple。

FCR 通过公开 JS API 连接，参考其 [`PublicAPI.ts`](https://github.com/obsidian-full-calendar-remastered/plugin-full-calendar/blob/main/Src/Api/PublicAPI.ts)。原 FCR 未做修改，保留其自身 GPL-3.0 许可；本独立插件采用 MIT 许可。
