# OB Calendar with Task on iCloud

## 当前目标

在 Full Calendar Remastered（FCR）源码上开发一个独立的 Obsidian 插件，在同一页面使用日历、待办和计时。以用户已经认可的「简洁待办计时」操作体验为参考，保留 FCR 的完整日历与数据同步基础。

已完成第一轮功能精简：移除 AI、天气、统计图表、成就月报、可用时间分享及上游更新弹窗，清理其命令、设置、默认值、翻译及依赖。另已移除 NLP 快速创建功能，语言精简为内置中文与英文。计时功能尚待整合。笔记库中正在使用的插件没有被替换。

## 用户已确认的范围

| 项目 | 决定 |
| --- | --- |
| AI / Agent | 删除 |
| 天气 | 删除 |
| 统计图表、分析和报告 | 删除；保留核心计时读数及单条记录的实际用时 |
| 分享 | 删除 FCR 可用时间分享／发布功能；保留云端已有共享日历的正常同步语义 |
| 侧栏 | 布局待用户进一步说明，暂不决定整体删除 |
| 主界面 | 待办、计时和日历统一到一个简洁页面 |
| 插件形式 | 最终仅需启用一个独立插件，不依赖原版 FCR 或另一个计时配套插件 |
| 待办来源 | 优先 Apple 提醒事项；若缺少可靠接口，用户接受其他待办来源 |
| 外观 | 简洁、中文优先，不增加花哨动画和额外复杂流程 |

尚待用户说明：侧栏中保留哪些区域、计时区域的位置、默认日历视图，以及后续具体交互。不要把上表中的“待定”当作已确认删除。
