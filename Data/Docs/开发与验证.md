## 开发命令

Node v24.14.0、pnpm 11.25.0。本机安装使用项目内依赖缓存：

```powershell
pnpm install --frozen-lockfile
pnpm run compile
pnpm test
pnpm run test:timer
pnpm run build
```

pnpm-workspace.yaml 将依赖缓存统一放到 Results/Cache/Pnpm-store。构建产物是 main.js、styles.css、manifest.json、LICENSE.md，另附 build-meta.json 供依赖审查。
