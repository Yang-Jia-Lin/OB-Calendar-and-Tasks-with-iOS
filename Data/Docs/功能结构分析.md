## 已删除

- features/agent/：AI 管理器、聊天侧栏及入口。
- features/weather/：天气读取、日历装饰与天气组件。
- chrono_analyser/：统计、分析、图表；移除 Plotly 库。
- features/milestones/：成就、操作统计与月报；事件写入仍保留。
- features/availability/：可用时间分享和发布；云端共享日历的正常同步继续保留。
- features/nlp/ 与 Data/Nlp/：文字快速创建日程的命令、图标、解析、弹窗、样式及专属测试。
- 其他语言翻译文件、远程翻译下载和遗留资源刷新模块；中英文资源直接内置。
- 上游更新弹窗与变更日志界面。
- 上游文档站、演示故事、CI 发布配置、开发钩子和贡献者工具。

构建配置改为仅输出 Results/Plugin/，不自动复制到 Obsidian。.git、.gitignore、必要构建配置、测试和许可证保留。

## 计时的下一步

Src/Reference/Simple-task-timer/ 是待移植参考，不参与主插件打包：

| 文件 | 可复用内容 |
| --- | --- |
| Src/core.cjs | 正向计时、暂停分段、持久化待写记录、确定 UID 与重试 |
| Src/tasks.cjs | Markdown 待办稳定身份与完成回写 |
| Src/ui.cjs、styles.css | 用户已认可的简洁界面 |
| Src/fcr.cjs | 原配套插件桥接；单插件整合后替换为内部调用 |

预期流程：选择任务 → 开始计时 → 暂停／继续 → 完成时先保存本机记录 → 写入选定日历 → 全部写入成功后完成原任务。失败保留待同步记录，避免丢失和重复写入。

TaskBacklogProvider 已提供 getTaskBacklogItems()、setTaskBacklogItemComplete()、ownsTaskId() 等接口。用来源 ID 与持久任务 ID 定位原任务，不能只用缓存会话 ID。

Apple 升级后的提醒事项可能只暴露 CalDAV 占位提示；保留 VTODO 支持不等于已经接入 Apple 新版提醒事项。重复任务的单次完成语义及真实 iCloud / iPad 验证仍待处理。
