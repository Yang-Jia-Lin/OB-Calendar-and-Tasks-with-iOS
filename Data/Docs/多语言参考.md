# 中英文界面说明

当前仅保留 Data/I18n/zh.json 和 en.json，由 Src/Features/I18n/i18n.ts 直接导入并打包。

- Obsidian 设置为中文时使用中文界面，兼容 zh、zh-CN、zh-TW 等语言代码。
- 其他语言设置使用英文。
- 中文缺少某个文字时回退到英文；两者都没有时返回翻译键。
- 初始化不读取旧翻译缓存，不发起网络请求，因此首次启动也可离线显示中文。
- 日历自身的星期、月份等文字只加载对应中英文配置。

此处的语言资源用于界面文字。NLP 文字创建日程功能及规则已经删除，添加事件继续使用普通表单。

修改界面文字时直接编辑上述两个 JSON 文件，然后运行 pnpm run build。没有额外的在线翻译部署步骤。
