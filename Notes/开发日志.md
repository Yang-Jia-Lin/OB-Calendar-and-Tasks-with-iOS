## 2026-11-07｜Windows 首版预览与 OB 连接实现

- 用户确认：首版同时提供主窗口、贴桌面底层月历＋选中日摘要、计时灵动岛、待办排序／按日安排／改期／撤回及撤销；先功能后 UI。睡眠／休眠继续计时，日记手动及自动更新保留，允许经原生往返验证的应用备注区。
- 实现：Tauri 2 原生宿主、独立 Node 后台与固定 Python 适配；本机 HTTP／SSE 鉴权、同次提交的请求确认、稳定身份、离线队列、冲突／恢复及受控迁移。UI 与 OB 共享唯一后台；旧完整模式默认保留。运行时随包提供，不在正常启动中在线安装依赖。任务安排独立于截止，损坏备注区停止写入，重复推进清除旧安排，已发送请求内容保持不变。
- Windows 实测修复：同步建窗导致的死锁改为异步／独立线程；桌面面板改挂实际图标宿主而非假定壁纸 WorkerW；屏幕与桌面客户区坐标显式转换，处理虚拟桌面负原点；灵动岛窄窗口不再继承主窗口的双行计时布局。
- 检查：TypeScript、280 核心／本机传输、22 Python、10 桌面浏览器及 167 旧 UI 回归通过。真实随包后台另通过 10 个隔离场景，包括独立启动、重复结束、60 次本地操作、退出落盘、启动失败释放互斥与实际 Python 空闲退出／重启；没有使用真实账户。
- 性能：最初沙盒 P95 约 1.5s，普通进程初测 220ms；消除备份重复写入／fsync 后，空闲隔离样例多次测得 86～169ms，最终随包复查为 169ms、后台启动 920ms。编译并行时曾测得 315ms，不能把并发负载结果写作已达标；空闲结果也不代替真实业务验收。原生主窗口内容就绪约 1.6s。此前锁屏采样 296.8MB／379.4MB、解锁主窗关闭采样 462.8MB 可能混入 PID 复用后的旧子进程，不能作为最终占用成绩；统计已加进程创建时间校验。因初测超出目标，已增加隐藏 WebView 暂停／恢复，以及 Python 30 秒空闲退出、下次请求重启；等待验证码时保留会话。350MB 目标仍待修正统计后的实测，不宣称通过。
- 产物：Windows x64 NSIS 安装包约 39.7MiB，桌面程序 0.1.0、插件 0.7.0；报告／截图在 Agents/Tests/Desktop 与 Agents/Tests/Visuals。Windows SDK／MSVC 采用项目内便携工具；系统安装器未完成，沙盒 SDK／NSIS 解压失败后以受控普通进程完成，未跳过包哈希核验。
- 实机与未完成边界：解锁后查看了主窗口、灵动岛收起／展开，核对跨窗口启动和暂停同步；用户手动确认 Win+D 后两者可见、日历可以点击。随后用户按 Esc 停止电脑控制，已停止 UI 自动操作；隐藏暂停后的重新打开、资源管理器重启、物理睡眠／休眠、多屏／DPI、Apple 原生备注往返、实际 Components／日记及正式业务迁移仍待验收。Mac 未实现。
