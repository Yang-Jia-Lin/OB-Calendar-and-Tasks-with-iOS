# 使用与迁移

更新：2026-11-08。PC 0.1.2，OB 0.8.1。现有用户已交接，以下日常流程使用桌面后台。

## 日常使用

PC 管理待办、安排、日程、计时、记录、账户及同步。关闭主窗口继续后台运行；托盘明确退出会保存为暂停。桌面日历和灵动岛可分别显示／隐藏。

OB 的 Components 卡片按钮沿用原任务绑定：开始计时，再次点击默认结束并只记工时，不自动完成提醒事项。没有绑定时选择桌面已有待办，不按课题标题重复创建任务。App 未启动时按钮尝试唤起它；连接失败会提示，不在 OB 创建另一套计时器。

OB 设置提供“启动时关闭反向链接和全部属性”“隐藏左侧四个快捷入口”、日记目录、时间轴模板。默认保留自动关闭，当前笔记属性不受影响；关闭开关可保留手动布局。左侧默认隐藏 Templater、Open Git source control、AI 对话（新标签页）和 Insert Callout，插件后注册按钮时也保持隐藏；关闭此开关后遵循 Obsidian 原来的显示设置，原本手动隐藏的项需在快捷栏右键菜单重新勾选。计时按钮 API、日记按钮、命令和 Templater 自动入口保留。

## 更新程序

从托盘退出旧 PC 应用，运行新安装包，选择原目录覆盖安装，无需卸载、清空数据或重复交接。数据仍在 `%LOCALAPPDATA%/CalendarTaskTimer/Desktop`。程序安装目录可自行选择。

OB 更新仅复制 main.js、manifest.json、styles.css，之前备份旧程序；不改 data.json、历史、会话或迁移目录，不自动重新加载。准备好后由用户重启 Obsidian 加载新版。

已完成的安排日期往返验证和旧 OB 导入入口会自动收起。安排日期与截止日期独立；往返验证只在当前配置首次启用安排日期时需要一次。

## 尚未交接的旧用户

0.8.0 没有旧完整工作台或“准备交接”命令。需要迁移时先使用 Results/Obsidian/V0.7.0_calendar-task-timer 保留版本：

1. 结束旧计时，等待同步／登录结束，从托盘完全退出 PC 应用。
2. 加载 OB 0.7.0，按 Ctrl+P 搜索“准备交接”，执行“日历与待办计时：准备交接到 Windows 桌面版”。
3. 保存提示中的交接目录，再打开 PC，在首次设置预览并导入快照。
4. 核对原任务身份、课题绑定、历史和未确认请求，随后加载 OB 0.8.0。

不得同时运行旧完整插件和桌面写入者。导入保护、凭据保护、原请求身份与备份机制保留；不能为精简界面而绕过这些规则。已有桌面业务时禁止覆盖导入。

## 日记

继续使用普通 Markdown，时间轴手动按钮、命令及 `updateDiaryFromNote`／Templater 自动入口均保留。快照来自桌面后台；日期使用“日记日期”或合法年月日文件名，不能用今天替代历史日期。

`<!-- ctt-diary-timeline:start -->` 与 `<!-- ctt-diary-timeline:end -->` 之间为生成区；区外手写内容保留，更新前仍备份。默认日记目录为 `00-Record/Calendar/Daily`，默认模板为 `Others/Template/日记时间轴模板.md`。

## 验收与回退

本机离线样例的 Win+D 和日历点击已由用户确认；实际睡眠／休眠、多屏／DPI、资源管理器重启和完整占用目标仍待验收。真实课题按钮及日记在加载新版后核对；不把隔离测试说成真实账户全通过。

回退前结束并退出桌面，备份桌面与旧交接目录，核对待提交请求。桌面产生的新业务不能通过覆盖旧日志自动回灌。旧插件与旧安装包分别保存在对应目录；Mac 轻量工具尚未交付。
