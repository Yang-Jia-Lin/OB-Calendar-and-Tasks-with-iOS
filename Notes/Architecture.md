# 当前架构与范围

更新：2026-10-30，OB 阶段版本 0.2.11。本文取代旧多份需求和架构草案，历史原文已在整合前本地备份。

## 范围

当前产品是 Obsidian 桌面工作台，本地 Markdown 待办、正向计时和可编辑时间轴；日历使用现有 FCR 公开 API。Apple 提醒事项是独立探针，尚未接入。

长期约束：云端业务数据仅用 iCloud，不建额外任务云或中转服务器；待办只用真正提醒事项或本地文件，不用日历事件模拟。未来可以有 Windows 客户端，iPad 优先用原生应用，Android 可暂只看日历／工时。只同步已保存结果，不接力活动计时。未验证的重复待办、子任务和复杂字段不回写。

未预建 Windows／移动端工程、完整 Repository 草案、备用日历待办协议或 AI／天气／统计／自动排程。后续按新需求和实测推进，不从历史草案自动恢复功能。

## 模块

| 位置 | 职责 |
| --- | --- |
| `Coding/Shared` | 模型、计时、UTC 区间、时间轴、后台队列 |
| `Coding/Providers/Fcr` | 授权、日历能力、UID 对账与修改保护 |
| `Coding/Clients/Obsidian` | 生命周期、设置、Markdown、原子日志、DOM、视图和对话框 |
| `Coding/Preview` | 复用真实 UI／控制器的模拟宿主 |
| `Coding/Probes/IcloudReminders` | 独立 Python 提醒事项验证，不参与插件构建 |

Shared 不导入宿主、窗口或文件系统，副作用由接口注入。视图和对话框共用 `dom.ts`，避免编辑窗口依赖整个视图模块。

## 数据与同步不变量

- Markdown 保留 `simple-task` 稳定 ID，分类与手动顺序使用隐藏元数据；更新不移动正文、标题和附属笔记，发现外部变化拒绝旧请求。
- 分类绑定可写 CalDAV 稳定 ID。“全部”只筛选；失效分类不改投。默认继承旧设置，或唯一匹配“科研”，否则明确选择。
- 日志 schema 2 兼容 1；会话 ID、分段 UID、确认状态和移动进度不变。时间点存 UTC、本地显示；暂停不计时，工时不得在未来。历史编辑不改变原待办分类。
- 日志临时写入、fsync、保留 previous 后原子替换；损坏原件保留，不以空状态覆盖。
- 本地短锁落盘，远端等待在锁外。新本地待办先完成 Markdown 再上传，旧导入记录保留原顺序。检查点合并当前状态，不覆盖新的活动会话。
- 后台单远端通道；网络退避，授权重连，冲突等待核对。15 秒只提示慢请求，不假装取消后并发重发。重载保留远端租约，日志写入者代次阻止旧实例覆盖。
- 编辑先落盘 before／after。跨分类按“目标确认 → 检查点 → 来源删除确认”推进；返回成功不等于移动完成。真实外部修改／删除停止，不自动重建。删除保留 tombstone，HTTP 404 不直接当成功。
- FCR false 返回后请求刷新，再按 UID 对账。比较忽略 href／ETag，只规范化单次非全天事件的等价零秒和缺省字段；真实秒数、日期、时区、标题和说明变化仍保护。全天／重复事件交给 FCR。

本插件只得到 FCR 缓存视图，不提供独立服务端事务。下一步先验收真实 OB/FCR/iCloud 恢复与编辑，再决定提醒事项接入。顶部计时／日历标签保留为后续方向。
