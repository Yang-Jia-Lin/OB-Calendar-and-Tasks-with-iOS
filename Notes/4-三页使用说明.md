# 0.4.0 计时／待办／日历

升级后结束当前计时，再重新启用插件或重启 Obsidian。安装只覆盖三个程序文件，不会自动重载，也不会改变待办 ID、Components 绑定、日记模板、会话或待同步记录。

课题卡片首次点击时，自动使用笔记标题（去掉.md）作为待办名；弹窗只选择分类，默认使用插件默认分类，确认后创建并开始计时。无需先手工添加待办或重传Components脚本。取消不会创建。已绑定课题继续复用原待办；设置中的“修改分类”或脚本参数true可打开分类选择。

首次打开进入待办；以后恢复上次页签。开始计时不会强制跳页，页签的小提示、任务行和 Components 按钮都对应同一会话。

## 计时

显示当前任务、累计时间、暂停／继续、结束并完成及只记时间。“只记时间”保留任务未完成；“结束并完成”额外完成原任务。

计时页上方为沉浸计时，下方为可独立选日期的执行记录，不显示候选待办或置顶列表。到顶部“待办”页签或 Components 卡片开始任务，再切回计时即可。

## 待办

新增、分类、排序和编辑沿用原方式。选中具体分类后新增默认使用该分类，“全部”使用设置默认；手动选择会保留到提交或更换分类筛选。日期仍表示截止日期。

点击右上方“筛选”按钮，展开关联、完成状态和截止筛选；选项可以组合，按钮显示生效的筛选数量。点击空白或 Escape 关闭。“Components 已关联”查已有稳定绑定，选择“未关联”可以隐藏课题待办。周期性日历任务本轮尚未合并进本地待办。

点击任务标题进入编辑，选择“删除待办”并确认即可移除，已有工时与完成历史保留；正在计时的任务需先结束。删除和勾选完成是两个独立操作。

关联课题的待办被删除后，下次从 Components 开始时按原稳定绑定和保存的任务信息重建一项；已完成时重新打开再计时，不添加额外完成记录。没有旧快照的已删除绑定使用课题文件名与默认分类恢复，不按标题匹配其他待办。换了待办文件路径或出现重复 ID 时会要求重新核对，不盲目重建。其他任务正在计时时也不会重建或抢占。

任务行可开始、暂停或继续当前会话；其他任务不会抢占正在计时的会话。勾选完成后可以切到“已完成”或“全部状态”查看，取消勾选可重新打开。

计时页下方的执行记录有独立日期，只展示该日已记录工时，不显示完成事项卡片。只记过时间但未完成的任务也有工时。插件手动勾选与结束并完成保存准确完成时间；旧任务、外部勾选没有记录时显示完成时间未知。取消完成不删除历史完成动作，再完成会新增一次动作；这些元数据不会显示在执行记录中。

待办页只显示待办，计时页的计时和执行记录一起滚动；顶部导航固定在内容滚动区外，没有顶部留白；直接是分段页签和统一线条工具按钮，没有产品标题行；计时页签圆点提示运行／暂停状态。切页保留各页草稿、筛选和滚动位置；这些临时界面状态不承诺关闭窗口后恢复，最后页签会持久保存。

## 日历

日历已由本插件直接连接 CalDAV，不再调用 FCR。首次加载新版会从原 FCR 配置导入日历 ID、名称、颜色、连接和显示偏好，把密码复制到本插件的库级安全凭据键；不删除旧配置或凭据，不把密码写入 JSON。当前库的 6 个日历与 1 个 CalDAV 待办来源已只读验证可接管。安装不会自动重载；请先结束计时，再重新启用本插件，确认连接成功后可停用 FCR。若凭据缺失，在本插件设置中补应用专用密码。

日历首次进入才创建，切页复用，支持月／周／日／列表；窄栏首次进入周视图会使用三日。连接的默认视图、时区、每周起始日、显示时段、周末及全天区域在本插件设置中调整。“日历分类”控制显示，不删除云端日程。设置中可添加、发现、编辑或移除 CalDAV／ICS 连接；移除连接不删除云端内容。

点击空白或“新建日程”创建；点击已有内容编辑。普通日程可以拖动改期／缩放时段。全天结束日为不包含的边界，例如 11月2日一天应设结束日 11月3日。支持不重复／每日／每周／每月／每年及保留现有自定义规则。周期编辑和删除作用于整个系列，单次例外编辑与拖动暂不开放；现有例外日期、提醒和其他字段在原资源中保留。CalDAV 待办显示截止时间，系列完成会明确提示整个系列；它不是 iCloud 原生提醒事项接入，也不自动合并进本地待办。

本地操作先写日志，再后台按稳定 UID、ETag 条件写入；断网保留草稿并退避重试，真实冲突停止覆盖。后台每两分钟同步，刷新可立即触发；失败保留最后有效快照并显示错误。首次全量同步需要时间，之后只下载 ETag 变化的资源；每秒计时不读取云端。ICS 为只读订阅。

## 功能修改位置

界面在 `Coding/Clients/Obsidian/ui.ts` 与 `styles.css`；筛选、重要任务和应用接口在 `Coding/Shared/application.ts`；完成记录在 `tasks.ts`；日历视图在 `calendarPanel.ts`，连接设置／迁移在 `calendarSettings.ts`／`calendarStorage.ts`，独立读写、缓存和 iCalendar 处理在 `Coding/Providers/Calendar/`。它们属于本插件，不需要额外上传 Components 脚本。

原 Components 脚本和日记更新入口兼容保留。日记模板与排版修改方式仍见 [日记时间轴使用](3-日记时间轴使用.md)。本轮未调整日记正文／模板。

未来桌面端将接入共享任务、日志与活动会话；本版只准备接口和设备身份，尚未实现跨设备接管或离线冲突处理。
