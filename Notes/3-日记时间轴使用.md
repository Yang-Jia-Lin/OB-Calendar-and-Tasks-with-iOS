# 日记时间轴怎么用、在哪里修改

从 0.2.17 开始，这是“日历与待办计时”插件的功能。日记中的代码块只渲染一个“更新时间轴”按钮，不包含需要逐篇维护的 JavaScript。点击按钮后生成普通 Markdown 时间轴；停用插件后，已保存的文字和表格仍然可读。

## 使用

加载支持日记功能的插件后，新建日记按现有 Daily Template 生成，带更新按钮和时间轴生成区；个人补充区、新记／修改查询及星期六提醒的位置由你自己的模板控制。

从 0.2.19 开始，本机 Daily Template 底部加入单次自动入口：日记创建后，等 Templater 全部执行并保存完成，自动调用同一时间轴更新接口一次。普通编辑／保存、打开旧日记不会触发；手动按钮仍保留。日历或插件未就绪时提示“日记已创建，时间轴未自动更新”，保留原文，稍后可点击按钮重试。该入口只需已有日记接口，兼容已加载的 0.2.17／0.2.18，不必为入口重载计时插件。模板中用户自行调整的排版以实际文件为准，自动入口不会恢复已删除的说明或手写区。

旧日记：先打开该笔记，在命令面板执行“日历与待办计时：更新当前日记时间轴”。第一次会在属性区后插入按钮和时间轴，保留原来全部正文；不批量删除旧汇总。以后点击笔记内按钮即可更新。在阅读视图或实时预览中可操作按钮，源码模式显示其代码块。

日期优先读取笔记的 `日记日期`，没有此属性时从中文年月日文件名提取；不使用电脑当天日期替代历史日记日期。默认只处理 `00-Record/Calendar/Daily/` 下具有合法年月日文件名的 Markdown 日记，目录可在插件设置中修改。

生成内容与插件时间轴使用同一批已加载日历数据和本机已结束工时；显示全天／跨日事项、日历名称及本机工时的待同步状态。普通日程不等于已经执行，表格用“日程／实际工时”区分。正在进行的计时不会被停止或作为已结束工时写入。

0.4.0 起直接使用本插件的独立日历快照，已包含当天周期日程展开；请在本插件日历同步完成后再更新日记。日历未连接或来源缓存未齐全时保留旧内容并提示。日记按钮只写当前已加载数据与本机工时，不把按钮点击当作强制完成所有云端同步。模板、生成区标记和手写区域规则不变。

## 修改位置

| 想改什么 | 修改位置 |
| --- | --- |
| 新日记各部分的位置、个人补充区、新记和修改的排列 | Obsidian：`Others/Template/Daily Template.md` |
| 生成区的标题、说明和排版 | Obsidian：`Others/Template/日记时间轴模板.md`，每次按按钮都会重新读取，不必重载插件 |
| 新建后自动更新一次的入口 | Daily Template 底部的 `cttDiaryAutoDone` 执行块；工程源为 `Coding/Clients/Obsidian/DiaryAutoUpdate.templater.md`，Templater 执行后不会把脚本留在日记里 |
| 日记目录、使用哪一份排版模板 | 插件设置 → 日记时间轴 |
| 如何读取／筛选日期、生成每行内容、保护更新范围 | 工程：`Coding/Clients/Obsidian/diary.ts`；日历及文件读写接线在 `plugin.ts` 的 `initializeDiary()` |
| 按钮文字和状态显示 | 工程：`Coding/Clients/Obsidian/diaryButton.ts`；样式在 `styles.css` 的 `.ctt-diary-controls` |

排版模板支持三个占位符：`{{timeline}}`（时间轴表格，必须且只能出现一次）、`{{date}}`（日记日期）、`{{updated}}`（本机快照生成时间）。缺少排版模板文件时使用内置默认排版；已有模板不合法时停止更新，不覆盖旧快照。普通日程表格行格式的修改目前需要改 diary.ts 并重新构建，不能只改占位符。

## 手写内容放在哪里

以下两个标记之间属于生成区，按钮会替换其中全部内容：

```html
<!-- ctt-diary-timeline:start -->
<!-- ctt-diary-timeline:end -->
```

想法和补充写在标记之外的“我的补充”或其他正文位置。不要删除／复制生成区标记。标记异常、更新过程中日期或生成区被手动修改时，会停止更新；标记之外同时新增的内容会保留。

每次实际更新前，在库内 `.obsidian/plugins/calendar-task-timer/diary-backups/` 保存一份更新前笔记，文件名为时间戳和随机 ID。不自动删除备份；如需恢复，先复制出备份核对，再将需要的内容还原。备份、日记及账号数据不进代码仓库。
